# FocusGuard – Focus and Productivity Management System

FocusGuard is a Java-based productivity application designed to help users manage focus sessions, organize tasks, track productivity, and record personal reflections. It provides a graphical user interface for accessing different productivity features in one place.

## Features

- **Dashboard:** Provides an overview of the application.
- **Focus Sessions:** Helps users manage and track focus sessions.
- **Task Management:** Organizes tasks and daily activities.
- **Session History:** Allows users to review previous focus sessions.
- **Analytics:** Displays productivity-related statistics.
- **Focus Journal:** Allows users to create and save personal notes and reflections.
- **Journal History:** Organizes saved notes into cards that can be selected to view complete entries.
- **Data Export:** Exports focus-session records into CSV format.
- **Profile:** Provides a section for user-related information and settings.

## Technologies Used

- Java
- Java Swing
- MySQL
- JDBC
- File Handling
- CSV

## Project Structure

The application is organized into separate modules for the graphical user interface, focus-session management, data access, journal functionality, and data export. The exact package and class structure depends on the implementation in the source code.

## How It Works

1. Launch the FocusGuard application.
2. Navigate through the sidebar to access different modules.
3. Start and manage focus sessions.
4. Organize tasks and review session history.
5. View productivity information through analytics.
6. Create and browse journal entries.
7. Export focus-session records as a CSV file.

## Setup and Execution

1. Install a compatible Java Development Kit (JDK).
2. Clone or download this repository.
3. Open the project in an IDE such as Visual Studio Code or Eclipse.
4. Configure the MySQL database connection if required by the implementation.
5. Compile and run the application's main Java class.

**Note:** Database configuration and execution steps may vary depending on the project's source code and environment.
